# План лабораторной № 3 «Запуск бота для реального использования»

Способ: облачный хостинг Railway. Бот сохраняет polling и SQLite.
Код остаётся в `lab1`, материалы этой лабораторной находятся в `lab3`.
Статус на 10.10.2026: выполнены локальные действия пунктов 1–2 и локальные доработки
по промпту v002. Для пунктов 3–5 выданы инструкции; пользователь работает в браузере,
внешние результаты не подтверждены проверкой ассистента. Пользователь собирает фидбэк.
Создание облачных ресурсов, деплой и платные операции ассистент не выполнял.

## 1. Подготовить проект — локальная подготовка выполнена

- Проверить Python, зависимости, команды, ошибки и напоминания автотестами.
- Проверить хранение токена в переменных окружения и исключение приватных файлов из Git.
- Сделать согласованную резервную копию SQLite и проверить её целостность.
- Создать папку `lab3` для материалов лабораторной.

Результат: Python 3.14.7, 55 исходных тестов пройдены, конфликтов зависимостей нет;
локальная конфигурация корректна, база скопирована через Backup API без изменения
источника, приватные файлы исключены из Git. Реальный сеанс Telegram на этом этапе
не проводился; ручную проверку нужно выполнить до допуска реальных пользователей.
