# Промпты лабораторной № 3

[v001.md](v001.md), 10.10.2026 — подготовка проекта и конфигурации Railpack для Railway,
приватная резервная копия SQLite, правила исключения секретов, локальные проверки.

[v002.md](v002.md) — согласованные требования кнопочного интерфейса, быстрых
напоминаний, подтверждения удаления, фильтров и отдельных дедлайнов.
Статус на 10.10.2026: реализовано локально, 104 теста прошли; деплой не выполнялся.
Решения пользователя:
дата с необязательным временем; добавление только через кнопку или /add;
напоминание за час до срока предлагается, но не включается автоматически.
Подробный план: [improvements_plan.md](../improvements_plan.md).

Последняя реализованная версия промпта — v002. Ручная проверка новой версии:
[manual_checks.md](../manual_checks.md). Облачное обновление выполняет пользователь.

Новые требования сохраняются отдельными полными редакциями `v002.md`, `v003.md` и т. д.
Нумерация независима от лабораторных № 1 и № 2.
Исправления реализации без изменения требований не требуют новой версии промпта.
