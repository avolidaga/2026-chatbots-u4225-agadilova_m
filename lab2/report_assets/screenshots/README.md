# Скриншоты лабораторной № 2

Добавьте сюда реальные изображения работы обновлённого бота:

- `01_search.png` — поиск по части названия и описания.
- `02_edit.png` — изменение названия и описания, кнопки «Оставить»/«Очистить».
- `03_groups.png` — создание групп и список с числом активных задач.
- `04_task_group.png` — назначение, перенос и просмотр задач группы.
- `05_add_group.png` — выбор группы в диалоге `/add`.
- `06_group_delete.png` — удаление группы с сохранением задачи и напоминания.
- `07_validation_cancel.png` — неверный ввод, дубли названий и отмена диалога.
- `08_reminder.png` — напоминание с актуальными данными задачи.

В [отчёте](../../lab2_report.md) замените текстовую заглушку на вставку, например:

```markdown
![Поиск по части названия](report_assets/screenshots/01_search.png)
```

Пути в отчёте относительные для просмотра в репозитории. До добавления изображений
заглушки остаются текстом, чтобы не показывать несуществующие фотографии.
Ссылку на видео добавьте в раздел 4.4 отчёта. Не публикуйте токен, `.env`, содержимое
рабочей базы и личные данные других пользователей.
