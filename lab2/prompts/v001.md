# Промпт для лабораторной работы № 2

Дата подготовки: 04.10.2026.
Статус: первая версия реализована и проверена 04.10.2026; база — lab1 v002.
Единственный промпт лабораторной № 2. История сообщений исключена.

Улучши моего Telegram-бота, добавив расширенную работу с простой базой данных SQLite.

Текущий функционал бота:
- Персональный ассистент для задач на Python с python-telegram-bot.
- SQLite хранит задачи с названием, описанием, приоритетом, статусом и напоминанием.
- Обычное сообщение или /add <название> быстро создаёт задачу.
- /add без параметров запрашивает название, необязательное описание, приоритет
  и необязательное напоминание. Есть кнопки приоритета и «Пропустить».
- /cancel отменяет создание; /start и /help знакомят с возможностями бота.
- /list показывает активные задачи; /list_all — все, включая выполненные.
- /priority <id> <приоритет>, /done <id>, /delete <id> управляют задачами.
- /remind <id> ДД.ММ ЧЧ:ММ устанавливает напоминание, /remind_off <id> отменяет его.
  Поддерживается дата с годом; короткая дата относится к текущему году.
- JobQueue отправляет напоминания по данным SQLite и восстанавливает их после перезапуска.
- Бот работает в личных чатах; каждый пользователь видит и изменяет только свои задачи.
- Настройки загружаются из .env; есть обработка ошибок и автоматические тесты.

Новый функционал:
- Добавь /search <текст>: находи собственные задачи по подстроке названия или описания,
  включая выполненные. Полное название не требуется: /search продук должно находить
  «Купить продукты», /search отч — «Подготовить отчёт».
- Поиск не учитывает регистр, в том числе в кириллице. Символы % и _ считай обычными
  символами запроса, а не шаблонами SQL. Совпадения только в описании тоже показывай.
- В /search показывай ID, название, описание при наличии, дату создания,
  приоритет, статус и напоминание. Сохраняй сортировку по приоритету и порядку создания.
- Все выборки ограничивай текущим Telegram user_id; ID другого пользователя
  не должен приниматься как параметр команды.
- На пустой поиск и неправильные параметры команд показывай понятную подсказку.
  На пустую выборку сообщай об отсутствии задач. Длинные ответы разбивай на сообщения.
- Обнови /help и меню Telegram новыми командами. В примерах ID используй <id>.
- Добавь /edit <id> — пошаговое изменение названия и описания. Покажи текущие значения;
  кнопка «Оставить» сохраняет соответствующее поле, «Очистить» убирает описание.
  Обновляй задачу только после завершения диалога; её ID, дата создания, приоритет,
  статус, группа и напоминание должны сохраняться. Доставляемое напоминание использует
  актуальные название и описание из базы.
- Добавь личные группы задач. Задача принадлежит одной группе либо находится без группы.
- /group_create запрашивает название и создаёт группу.
- /groups показывает ID, названия групп и количество активных задач в каждой.
- /group_tasks <group_id> показывает все задачи группы, включая выполненные.
- /group_rename <group_id> запрашивает новое название группы.
- /group_delete <group_id> удаляет только группу; её задачи сохраняются без группы,
  с прежними статусами и напоминаниями.
- /task_group <id> предлагает выбрать группу кнопками и назначает её задаче.
  Повторное назначение переносит задачу в другую группу.
- /task_ungroup <id> убирает задачу из группы, не удаляя её.
- Название группы должно быть непустым, однострочным, не более 80 символов UTF-16.
  Не допускай одинаковые названия групп одного пользователя без учёта регистра.
  Разные пользователи могут иметь группы с одинаковыми названиями.
- В пошаговой /add после выбора приоритета предложи необязательный выбор группы
  с кнопкой «Пропустить», затем запроси напоминание. Если групп нет, пропусти выбор
  группы автоматически. Обычный текст и быстрая /add создают задачу без группы.
- Название группы показывай в списках, поиске и напоминаниях.
- /cancel отменяет любой текущий диалог без сохранения частичных изменений.
  /start сбрасывает диалог; новая команда, запускающая диалог, заменяет старый.
  /help и команды просмотра не сбрасывают введённые ответы.
- Проверяй владельца как задачи, так и группы при каждом чтении и изменении.
  Чужие ID и подделанные ответы клавиатуры не дают доступа к чужим данным.
- Историю переписки не сохраняй, таблицу messages и команду /history не добавляй.
  Пользователь просматривает историю общения средствами Telegram.
