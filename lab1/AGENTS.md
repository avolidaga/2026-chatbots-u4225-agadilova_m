# Работа над lab1

- По указанию пользователя все изменения этой лабораторной выполняются внутри `lab1`.
- Исходный промпт сохранён в `prompts/v001.md`.
- При редактировании требований сохраняй полный обновлённый промпт отдельным файлом
  `prompts/v002.md`, затем `v003.md` и т. д. Не перезаписывай старые версии.
- Обновляй ссылку на текущую версию и краткую историю в `prompts/README.md`.
- Исправление реализации без изменения требований не требует новой версии промпта.
- Не включай реальные токены, `.env` и пользовательскую базу в Git или документацию.
