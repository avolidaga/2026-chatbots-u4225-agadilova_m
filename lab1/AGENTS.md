# Работа над lab1

- Код общего бота, тесты, зависимости и инструкция запуска находятся в `lab1`.
- Материалы лабораторной № 2 (план, новые промпты, будущий отчёт и его ресурсы)
  по указанию пользователя сохраняй в соседней папке `lab2`.
- Конфигурация сборки лабораторной № 3 также находится в `lab1`; её материалы и
  независимая история промптов — в соседней `lab3`. Учитывай этапы из `lab3/AGENTS.md`.
- Исходный промпт сохранён в `prompts/v001.md`.
- При редактировании требований сохраняй полный обновлённый промпт отдельным файлом
  `prompts/v002.md`, затем `v003.md` и т. д. Не перезаписывай старые версии.
- Обновляй ссылку на текущую версию и краткую историю в `prompts/README.md`.
- Для лабораторной № 2 используй `lab2/prompts/README.md`: нумерация независима,
  до первой реализации редактируй единственный `lab2/prompts/v001.md` без повышения версии.
- Исправление реализации без изменения требований не требует новой версии промпта.
- Не включай реальные токены, `.env` и пользовательскую базу в Git или документацию.
