# История промптов

Текущая версия: [v002.md](v002.md).

`v001.md` — исходный промпт из переписки, по которому создан бот.

`v002.md` (01.10.2026) — необязательное описание, пошаговая `/add` с кнопками,
дата `ДД.ММ ЧЧ:ММ`, команды `/list_all` и `/remind_off`, заполнитель `<id>` в помощи,
миграция существующей базы и проверки нового диалога.

При изменении требований сохраняем полный обновлённый промпт в новом файле:
`v002.md`, `v003.md` и так далее. Старые версии не изменяем и не удаляем.
В этом README обновляем ссылку на текущую версию и кратко описываем изменения.
Исправления кода без изменения требований не требуют новой версии промпта.
