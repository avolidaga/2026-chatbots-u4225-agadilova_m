Создай Telegram-бота — персонального ассистента для задач — на Python с использованием библиотеки python-telegram-bot.

Назначение:
Бот помогает пользователю записывать задачи, организовывать их по приоритетам, получать напоминания и просматривать список дел.

Все файлы проекта создавай в папке lab1.

Функционал бота:

1. Добавление задач
- Принимай обычное текстовое сообщение как новую задачу.
- Также поддерживай команду /add <текст задачи>.
- Каждой задаче присваивай уникальный числовой ID.
- По умолчанию устанавливай средний приоритет.
- После добавления показывай ID, текст и приоритет задачи, а также подсказку о настройке напоминания.
- Пустые задачи не сохраняй.

2. Приоритеты
- Поддерживай три уровня: высокий, средний и низкий.
- Позволяй менять приоритет командой:
  /priority <ID> <высокий|средний|низкий>
- Обозначай приоритеты: 🔴 высокий, 🟡 средний, 🟢 низкий.
- В списке сначала показывай задачи с высоким приоритетом, затем со средним и низким. Внутри одного приоритета показывай задачи в порядке добавления.

3. Списки дел
- /list — показать все невыполненные задачи.
- /list all — показать все задачи, включая выполненные.
- Для каждой задачи показывай ID, текст, приоритет, статус и время напоминания, если оно установлено.
- Если список пуст, сообщай об этом понятным сообщением.
- Длинные списки разбивай на несколько сообщений с учётом ограничений Telegram.

4. Управление задачами
- /done <ID> — отметить задачу выполненной и отменить её напоминание.
- /delete <ID> — удалить задачу и её напоминание.
- Выполненные задачи сохраняй, пока пользователь их не удалит.

5. Напоминания
- /remind <ID> <ДД.ММ.ГГГГ> <ЧЧ:ММ> — установить напоминание.
- Пример: /remind 3 15.10.2026 18:30
- /remind <ID> off — отменить напоминание.
- Для каждой задачи допускай одно активное напоминание; повторная установка заменяет предыдущее.
- Используй часовой пояс из настройки TIMEZONE, по умолчанию Europe/Moscow.
- В подтверждении всегда указывай дату, время и часовой пояс.
- Не разрешай устанавливать напоминания в прошлом или для выполненных задач.
- В назначенное время отправляй сообщение с ID, текстом и приоритетом задачи.
- После перезапуска восстанавливай напоминания из базы данных.
- Если время напоминания наступило, пока бот был выключен, отправляй его после запуска с отметкой о задержке.
- Сохраняй факт успешной отправки, чтобы уже отправленные напоминания не повторялись после обычного перезапуска.

6. Знакомство и помощь
- /start — краткое приветствие, описание возможностей и пример добавления задачи.
- /help — список команд с примерами.
- Общайся на русском языке, кратко и дружелюбно.
- При неизвестной команде показывай подсказку /help.
- На фотографии, голосовые сообщения и другие неподдерживаемые вложения отвечай просьбой прислать текст.

Хранение данных:
- Используй SQLite.
- Храни ID задачи, Telegram ID владельца, ID чата, текст, приоритет, статус, дату создания, время напоминания и состояние его отправки.
- Данные должны сохраняться после перезапуска.
- Каждый пользователь должен видеть и изменять только свои задачи. Проверяй владельца во всех командах, принимающих ID.
- Бот предназначен для личных чатов. В группах предлагай перейти в личный чат и не показывай задачи.

Требования:
- Сделай код простым, понятным и хорошо прокомментированным на русском языке.
- Используй актуальную стабильную версию python-telegram-bot и совместимые зависимости.
- Используй long polling для локального запуска.
- Для напоминаний используй JobQueue библиотеки python-telegram-bot, а SQLite — для их сохранения.
- Загружай токен и настройки из .env. Не включай настоящий токен в код, примеры и логи.
- Обрабатывай неверный формат команд, некорректные даты, неизвестные ID, ошибки базы данных и Telegram API.
- При ошибке ввода показывай понятное объяснение и пример правильной команды.
- Добавь логирование технических ошибок.
- При отсутствии токена завершай запуск с понятной инструкцией.
- Не подключай внешнюю LLM: обработка задач должна работать без платных AI API.

Создай:

1. bot.py — код бота.
2. requirements.txt — зависимости с зафиксированными совместимыми версиями.
3. README.md — инструкцию для новичка:
   - создание бота через BotFather и получение токена;
   - требования к версии Python;
   - создание виртуального окружения;
   - установка зависимостей;
   - настройка .env;
   - запуск и остановка бота;
   - список команд и примеры;
   - расположение базы данных;
   - пояснение, что своевременные напоминания требуют работающего процесса бота;
   - сценарий ручной проверки основных функций, перезапуска и разделения данных двух пользователей.
4. .env.example — пример с TELEGRAM_BOT_TOKEN, TIMEZONE и DATABASE_PATH без настоящих секретов.
5. .gitignore внутри lab1 — исключения для .env, виртуального окружения, кэша Python, базы данных и её служебных файлов.
