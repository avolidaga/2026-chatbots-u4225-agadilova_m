Создай или обнови Telegram-бота — персонального ассистента для задач — на Python с использованием библиотеки python-telegram-bot.

Назначение:
Бот помогает пользователю записывать задачи с описанием, организовывать их по приоритетам, получать напоминания и просматривать список дел.

Все изменения проекта выполняй внутри папки lab1. Исходный промпт v001.md сохраняй неизменным. Эта версия учитывает правки пользователя от 01.10.2026.

Функционал бота:

1. Задачи и описание
- Задача содержит обязательное название и необязательное текстовое описание.
- Принимай обычное текстовое сообщение вне диалога как новую задачу без описания со средним приоритетом.
- Сохрани быстрый способ добавления: /add <название задачи>.
- Каждой задаче присваивай уникальный числовой ID.
- После добавления показывай ID, название, описание, если оно заполнено, приоритет и статус напоминания.
- Пустые названия не сохраняй. Ограничь суммарную длину названия и описания 3000 символами UTF-16, чтобы сообщения о задаче помещались в лимиты Telegram. При превышении объясняй, что нужно сократить текст.

2. Пошаговое добавление через /add
- Команда /add без параметров запускает диалог создания задачи.
- Первое сообщение: «Введите название задачи».
- После корректного названия: «Введите описание». Объясни, что описание необязательно, и предложи кнопку «Пропустить».
- После описания или пропуска: «Укажите приоритет (высокий, средний, низкий)». Покажи кнопки «высокий», «средний», «низкий». Разреши также ввод этих вариантов текстом.
- После приоритета: «Установить напоминание». Покажи формат ДД.ММ ЧЧ:ММ, пример, текущий год и часовой пояс. Предложи кнопку «Пропустить», чтобы создать задачу без напоминания.
- В короткой дате используй текущий год в TIMEZONE. Прошедшие даты не переноси автоматически на следующий год, а отклоняй с понятной подсказкой. Для явного задания года также разреши ДД.ММ.ГГГГ ЧЧ:ММ.
- Если выбран неверный приоритет, название пустое или дата некорректна, сохраняй текущий шаг и проси повторить ввод.
- Сохраняй задачу в SQLite только после завершения всех шагов, вместе с описанием, приоритетом и выбранным напоминанием одной операцией.
- /cancel отменяет создание, не добавляя задачу. /start и повторная /add начинают сценарий заново. /help и команды списков доступны во время диалога и не сбрасывают его.
- У каждого пользователя свой диалог; ввод в группе не изменяет личный диалог.
- После завершения или отмены убирай временную клавиатуру.
- Черновики диалога можно хранить в памяти: после перезапуска незавершённый диалог начинают заново, а сохранённые задачи остаются в базе.

3. Приоритеты
- Поддерживай три уровня: высокий, средний и низкий.
- /priority <id> <высокий|средний|низкий> меняет приоритет существующей задачи.
- Обозначай приоритеты: 🔴 высокий, 🟡 средний, 🟢 низкий.
- В списке сначала показывай высокий, затем средний и низкий приоритеты; внутри одного приоритета — порядок добавления.

4. Списки дел
- /list показывает невыполненные задачи.
- /list_all показывает все задачи, включая выполненные, и заменяет прежнюю /list all.
- Для каждой задачи показывай ID, название, описание при наличии, приоритет, статус и время напоминания, если оно установлено.
- Если список пуст, сообщай об этом понятно.
- Длинные списки разбивай на сообщения с учётом ограничений Telegram.
- На старый синтаксис /list all отвечай подсказкой использовать /list_all.

5. Управление задачами
- /done <id> отмечает задачу выполненной и отменяет её напоминание.
- /delete <id> удаляет задачу вместе с напоминанием.
- Выполненные задачи сохраняй до явного удаления.

6. Напоминания
- /remind <id> <ДД.ММ> <ЧЧ:ММ> устанавливает или заменяет напоминание; короткая дата относится к текущему году в TIMEZONE.
- Также разреши дату с годом: /remind <id> <ДД.ММ.ГГГГ> <ЧЧ:ММ>.
- /remind_off <id> отменяет напоминание и заменяет прежнюю /remind <id> off.
- На старый синтаксис отмены отвечай подсказкой использовать /remind_off <id>.
- На задачу допускай одно активное напоминание; новая дата заменяет предыдущую.
- TIMEZONE по умолчанию — Europe/Moscow. В подтверждении всегда показывай полную дату, время и часовой пояс.
- Не разрешай напоминания в прошлом или для выполненных задач.
- В назначенное время отправляй ID, название, описание при наличии и приоритет задачи.
- После перезапуска восстанавливай напоминания из SQLite. Если срок наступил во время остановки, отправляй с отметкой о задержке.
- Сохраняй факт успешной отправки, чтобы доставленные напоминания не повторялись после обычного перезапуска.
- Сохрани повторные попытки при временных ошибках Telegram API и обработку постоянных ошибок доставки.

7. Приветствие и помощь
- /start — краткое приветствие и предложение использовать /add.
- /help — список актуальных команд и примеры.
- Во всех примерах команд с ID в /help используй буквальный заполнитель <id>, а не число 3.
- Укажи в помощи /add, /list_all, /remind_off, /cancel и формат даты ДД.ММ ЧЧ:ММ.
- Общайся по-русски, кратко и дружелюбно.
- На неизвестные команды показывай подсказку /help.
- На вложения проси прислать текст; если открыт диалог, сохраняй его текущий шаг.
- Обнови меню команд Telegram под новый набор команд.

Хранение данных:
- Используй SQLite. Храни ID, Telegram ID владельца и чата, название, описание, приоритет, статус, дату создания, время напоминания и состояние доставки.
- Добавь миграцию для старой базы: новое поле описания должно появляться автоматически с пустым значением для существующих задач. Сохрани все старые задачи, ID, статусы и напоминания. Повторный запуск миграции должен быть безопасен.
- Проверяй владельца во всех командах, принимающих ID. Пользователь видит и изменяет только свои задачи.
- Работай в личных чатах; в группах предлагай перейти в личный чат.

Требования:
- Используй простую, хорошо прокомментированную на русском реализацию и существующие совместимые зависимости из requirements.txt. Проверь работу на установленном Python 3.14.
- Используй long polling, JobQueue и SQLite.
- Загружай настройки из .env. Не публикуй реальный токен и не включай его в логи и примеры.
- Обрабатывай ошибки ввода, дат, базы и Telegram API. После ошибки диалога сохраняй введённые данные, чтобы пользователь мог повторить текущий шаг.
- Не используй платные AI API или внешнюю LLM во время работы бота.
